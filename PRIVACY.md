# Privacy Policy

## Overview

Feedly Background Tab Open is committed to protecting your privacy and personal information.

## Data Collection and Usage

This extension performs the following operations:

- Controls article opening behavior on Feedly website
- Manages background tab display of articles

We DO NOT collect:

- Personal information
- Browsing history
- Cookie data
- Any other user data

## Permissions

This extension requires the following permissions:

- `tabs`: Required to open articles in background tabs
- `https://*.feedly.com/*`: Required to operate on Feedly website

## Data Sharing

- We do not share any data with third parties
- We do not serve advertisements or track users

## Changes to This Policy

If we make changes to this privacy policy, we will update this document and notify users of significant changes through extension update notes.

## Contact

If you have any questions or concerns about privacy, please contact us through GitHub Issues.
